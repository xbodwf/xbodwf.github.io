5. 代码 (Code)

你可以使用反引号 ` 来创建行内代码，例如 const a = 1;。

对于多行代码，可以使用代码块：

JavaScript
// Javascript 语法高亮
function greet(name) {
  console.log(`Hello, ${name}!`);
}

greet('World');
Python
# Python 语法高亮
def factorial(n):
    """
    Calculates the factorial of a non-negative integer.
    """
    if n == 0:
        return 1
    else:
        return n * factorial(n-1)

# 测试函数
print(f"5! is {factorial(5)}")
这是一个没有指定语言的普通文本块。
它不会有任何语法高亮。

11. 转义字符 (Escaping Characters)

如果你想显示 Markdown 的特殊字符本身，而不是让它们触语法，可以使用反斜杠 \ 进行转义。

*这不是斜体* # 这不是标题 ` 这不是代码 ` [ 这不是链接 ]

代码也可以在脚注中：`code_in_footnote()`
